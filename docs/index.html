WINDOW SYSTEM

Uma janela que se comporta como ferramenta, não como overlay improvisado.

Arraste, redimensione, minimize, maximize ou esconda. O estado da janela, a tab ativa e os controles permanecem consistentes.

01

Responsiva por construção

Modos Desktop, Tablet e Mobile com safe area, escala de 0.75 a 1.25 e colunas que empilham quando falta espaço.

02

Window manager completo

Drag sem jump, resize com limites, minimize/restore, maximize/restore e ReopenPill que preserva a mesma instância.

DRAGRESIZERESTORE
03

Estado utilizável

Controles stateful expõem Get(), Set() e Changed. Perfis podem permanecer em memória ou usar JSON quando o executor oferece filesystem.

Changed72
04

Navegação que escala

A sidebar adapta sua largura, suporta dezenas de tabs com scroll e mantém automaticamente a tab ativa visível.

INSTALL / MAIN

Uma linha para carregar.
Uma API para construir.

Use o bundle atual da branch main. O executor precisa oferecer loadstring e game:HttpGet; persistência em disco é opcional.

Luau MIT 24 módulos / 1 bundle
bootstrap.client.lua
local Axiom = loadstring(game:HttpGet(
  "https://raw.githubusercontent.com/Ryanabcraft/AxiomUI/main/dist/Axiom.lua"
))()

local Window = Axiom:CreateWindow({
  Title = "My Hub",
  Theme = "Dark",
  ReopenPill = true,
})

local Combat = Window:AddTab({
  Name = "Combat",
  Icon = "crosshair",
})
